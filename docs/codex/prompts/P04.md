# P04 Prompt: Local Platform via Docker Compose

PHASE ID: P04 - Local Platform via Docker Compose.

Implement local infrastructure only; still avoid product business features.

Services:

- PostgreSQL
- OpenSearch (single-node local profile, security configured appropriately for local trusted network but never exposed wider than needed)
- Keycloak
- OpenFGA
- MinIO
- OpenTelemetry Collector plus a practical local trace viewer/metrics path
- optional Redis only if an existing ADR requires it

Requirements:

- pinned version tags; prefer digest pinning where maintainable;
- explicit health checks and dependency readiness, not blind sleeps;
- non-root containers where supported;
- private compose network;
- bind ports to localhost by default;
- persistent named volumes;
- resource limits/config notes for OpenSearch;
- secrets loaded from environment/local secret file excluded from Git;
- separate demo defaults from production-like secure config;
- deterministic bootstrap scripts/migrations;
- `make up`, `make down`, `make reset-demo`, `make platform-status`.

Do not bake passwords into source. Development credentials can be generated/bootstrap-provided through documented local setup and `.env.example` placeholders.

Add smoke tests that verify services are reachable and expected versions/schema endpoints respond.

Document backup/reset semantics and data locations.

Run container lint/scans applicable now. Update ledgers and prompt archive.

# P13R: Evidence Store And Semantic Reranker Remediation

Resolve the two P13 residual risks only.

1. Add a production-shaped PostgreSQL and MinIO evidence-content store that
   validates canonical tenant, chunk, version, lifecycle, raw object hash, and
   citation locator relationships before returning text.
2. Replace the lexical local reranker runtime path with a configured, pinned,
   cache-only local semantic cross-encoder. Retain deterministic lexical code
   only for tests or safe fallback behavior.
3. Add unit and real local integration evidence. Keep retrieval, context
   construction, citations, external sharing, and generation out of scope.
4. Run applicable fast and release gates, update durable ledgers and risks,
   checkpoint the remediation, and push the commits to `master`.

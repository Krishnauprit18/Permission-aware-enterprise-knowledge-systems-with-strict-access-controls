## Objective

Define a secure local-first reference architecture, mandatory pipelines,
authorization enforcement, typed ports, dependency rules, versioning, deployment
topology, and evidence-backed technology decisions without business implementation.

## Delivered

- Python/FastAPI backend and worker, React/TypeScript strict frontend,
  PostgreSQL, OpenSearch, OpenFGA, Keycloak, MinIO, local model adapters,
  OpenTelemetry, and Docker Compose reference architecture.
- Redis explicitly deferred until a measured queue/cache use and new ADR exist.
- Normative ingestion, query, deletion/change, and role-change pipelines.
- Metadata-only hybrid candidates, current OpenFGA fine checks, and authorized
  types required before text fetch, reranking, evidence resolution, or LLM context.
- Ten required typed ports plus supporting context, citation, lifecycle, cache,
  object-store, checkpoint, and telemetry boundaries.
- Ports/adapters layering and enforceable import rules preventing framework SDKs
  from entering domain/application code.
- API, index schema, embedding, prompt, evaluation dataset, authorization,
  database/object, pipeline component, and release compatibility versioning.
- ADR-005 through ADR-010 with alternatives, rationale, security impact, and
  planned evidence.
- Invariant-to-architecture review with deferred validation risks.

# P11 Embeddings and Search Index Plan

## Scope

Implement the local embedding provider boundary, bounded embedding batches,
versioned OpenSearch mappings/documents, a private HTTP adapter, disposable
index generations and aliases, deletion propagation, and a deterministic demo
reindex command.

## Out of scope

P11 does not implement user query retrieval, authorization scope resolution,
reranking, evidence resolution, answer generation, or a browser-facing search
endpoint. OpenSearch metadata is never an authorization grant.

## Exit evidence

- Local-only embedding configuration and typed provider/runner contracts with
  bounded batches, timeout, retry, dimension, and version checks.
- Explicit OpenSearch schema generation, BM25/vector fields, security and
  provenance metadata, alias cutover, bulk indexing, and delete operations.
- Regression tests for mappings, known fixture indexing, deterministic
  metadata, deletion, reindex, version mismatch, and restricted metadata.
- `make reindex-demo` and operator documentation for local use.
- `make verify` and `make verify-release` pass; state and prompt ledgers are
  updated and this plan is moved to `completed/`.

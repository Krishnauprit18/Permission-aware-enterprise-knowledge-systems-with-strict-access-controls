# P09 Connector and Ingestion Plan

## Status

Active. This phase implements the connector and raw-ingestion orchestration
boundary for checked-in synthetic sources. It stops before parsing, chunking,
embedding, search, retrieval, reranking, and answer generation.

## Scope

- Typed source-envelope, raw-snapshot, ACL-intent, retry, and result contracts.
- Bounded document, support-ticket, Slack-thread, and call-transcript fixture
  connectors.
- Per-item orchestration with hash change detection, raw-store provenance,
  metadata/version persistence, ACL-intent handoff, tombstones, and cursors.
- MinIO and PostgreSQL adapters behind application ports.
- Regression tests for sync, replay, update, deletion, malformed input,
  restart, duplicate identity, hostile paths, ACL mapping, and retry.

## Exit checks

- `uv run --directory backend ruff format --check src tests`
- `uv run --directory backend ruff check src tests`
- `uv run --directory backend mypy`
- `uv run --directory backend pytest tests/unit/test_ingestion.py -q`
- `make verify`
- `make verify-release`
- `git diff --check`

## Security review points

- Paths stay beneath the configured root and are regular, bounded,
  allowlisted file types.
- Manifest hashes are checked against bytes before an envelope is emitted.
- Tenant mismatch, duplicate identity, stale resurrection, malformed input,
  and unsafe object keys fail closed.
- Source ACLs produce relationship intents only; connectors do not write
  OpenFGA or treat source body text as policy.
- Raw snapshots precede future parsing and carry allowlisted provenance.
- A failed item is not checkpointed and a cursor cannot cross a failure gap.
- Logs contain stable IDs and reason codes only, never content or secrets.

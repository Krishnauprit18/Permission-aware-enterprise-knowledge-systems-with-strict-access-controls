PHASE ID: P14 - Grounded Generation & Citation Integrity.

Implement answer generation using only authorized EvidencePackets.

LLM:
- provider interface;
- default local runtime adapter; no cloud dependency in default deployment;
- model configuration externalized;
- timeouts/token budgets/concurrency limits;
- no arbitrary tool execution by the answer model.

Context builder:
- evidence IDs are assigned by backend;
- include only authorized evidence;
- enforce context size budget deterministically;
- treat retrieved content as untrusted DATA;
- delimit evidence clearly;
- never concatenate source text into system/developer instruction positions.

Generation contract:
- answer only from supplied evidence;
- preserve tentative vs committed language;
- explicitly describe material conflicts;
- say insufficient accessible evidence when support is missing;
- factual claims should cite evidence IDs;
- structured response schema preferred over parsing free text.

Citation integrity:
- model may reference only provided evidence IDs;
- backend validates every citation;
- unknown/missing citation IDs fail validation and trigger safe retry/fallback;
- citation UI metadata comes from backend mapping, not model-generated URLs/titles.

Prompt-injection defenses:
- evidence instructions have no authority;
- no actions/tools;
- sanitize rendering;
- add adversarial tests using injected Slack content.

Tests:
- grounded happy path;
- no-evidence refusal;
- conflicting evidence;
- bogus citation attempt;
- prompt injection in evidence;
- unauthorized evidence assertion proving context builder rejects it;
- model failure/timeout returns safe error.

Version prompts and record prompt/model/version IDs in traces.
Update ledgers and archive prompt.

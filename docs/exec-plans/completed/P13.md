# P13 Reranking And Evidence Resolution

## Scope

Implemented post-retrieval ranking and deterministic evidence resolution using
only P12 authorized candidates. No retrieval widening, context construction,
citation validation, answer generation, external sharing, or API delivery was
added.

## Delivered

- Current `can_view` is re-checked before text is loaded from the typed evidence
  content-store port. A denied or cross-tenant candidate is never loaded.
- `LocalPairwiseReranker` provides a bounded offline query-document pair scorer
  with a cooperative 250 ms budget. It accepts only supplied authorized chunks
  and returns only stable evidence IDs.
- Reranker unavailable/timeout/invalid-ID behavior falls back to the existing
  authorized P12 order without retrying search or admitting another candidate.
- `EvidencePolicyMetadata`, `EvidencePacket`, `EvidenceResolution`, source
  groups, conflict records, annotations, and content-free trace diagnostics are
  typed and deterministic.
- Policy resolution sanitizes untrusted text, collapses duplicate/high-overlap
  adjacent chunks, preserves contradictory evidence, annotates freshness/status/
  authority/lineage, and exposes most-relevant separately from
  most-authoritative evidence.
- OpenSearch metadata-only candidate parsing now retains `ordinal` and
  `external_shareable`; these values are still not authorization grants.

## Residual limits

- The local pairwise reranker is a deterministic offline baseline, not a
  semantic cross-encoder quality claim.
- P13 defines the production evidence-content-store port, but only uses a
  deterministic test fixture adapter. Persistence-backed live evidence loading
  and end-to-end OpenSearch/OpenFGA proof remain future work.

# Product API And Web UI

## Boundary

The browser communicates only with the versioned FastAPI surface and the
Keycloak OIDC endpoints. It never receives PostgreSQL, OpenSearch, OpenFGA,
MinIO, model, or service credentials. The browser's answer mode is an
untrusted request value; the backend authenticates the principal and invokes
the complete retrieval, evidence, generation, and confidentiality composition
root before returning a response.

The product endpoint is `POST /api/v1/knowledge/query`. Its request contains a
bounded `question` (1-2,000 characters) and `mode` (`INTERNAL` or
`CUSTOMER_SAFE`). No client account, tenant, ACL, OpenSearch DSL, or resource
filter is accepted. FastAPI's generated OpenAPI document is the contract
source exposed at `/openapi.json`.

## Response contract

The response contains only backend-projected claims, citation metadata,
permitted excerpts, deterministic policy warnings, conflict and freshness
qualifications, and a request/trace identifier. Citation IDs and display data
come from validated `GroundedAnswer` values. The model cannot supply a URL,
title, classification, or evidence ID that the backend did not validate.

The `Why this answer?` view is provenance, not chain-of-thought. It displays
the evidence excerpt, source type/locator, update date, classification, and
deterministic conflict/freshness annotations. It does not display hidden
prompts, model reasoning, raw authorization graph data, or infrastructure
diagnostics.

## Failure and browser security

- Missing or unconfigured query composition returns a generic structured 503;
  no stack trace, source title, or protected existence is returned.
- Invalid request bodies return a generic 422 envelope and never echo the
  submitted query or unknown fields.
- Correlation IDs are generated by the server and returned as `request_id` for
  support diagnostics.
- The API uses an Authorization header with the existing memory-only OIDC
  token store, so the browser does not use bearer tokens in localStorage or
  cookies. A future cookie/BFF mode must add CSRF protection before enabling
  state-changing routes.
- API and local frontend responses set CSP, frame, referrer, content-type, and
  permissions headers. The dev Vite CSP permits only its own React refresh
  inline preamble; the preview policy does not.
- React renders retrieved text as text nodes. No `dangerouslySetInnerHTML` or
  active-content renderer is used.

## Composition status

P16 adds the typed `QueryAnswerService` port and HTTP/UI boundary. The default
API composition root intentionally does not invent a demo answer or silently
construct a partial pipeline: when a production query service is not injected,
the protected request fails closed. Integration tests inject a complete typed
answer to prove the contract. Wiring the live P12-P15 adapters, persistence
repositories, and local model runtime into this port remains an explicit
composition/integration task; the UI cannot bypass that boundary.

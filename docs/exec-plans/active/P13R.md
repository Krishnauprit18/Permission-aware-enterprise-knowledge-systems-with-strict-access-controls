# P13R Evidence Store And Semantic Reranker Remediation

## Scope

Close P13 residual implementation gaps only. Wire a production-shaped
PostgreSQL/MinIO evidence-content adapter with canonical integrity checks and
replace the lexical runtime baseline with a pinned cache-only local semantic
cross-encoder. Do not add query retrieval, context construction, citations,
generation, or external-sharing features.

## Exit Gate

- The evidence store rejects inactive, cross-tenant, wrong-version, wrong-hash,
  and locator-mismatched records before returning text.
- The MinIO reader verifies URI confinement, bounded bytes, and SHA-256 before
  any P10 reconstruction.
- The local semantic adapter is pinned, cache-only, bounded, and operates only
  on supplied authorized chunks.
- Unit and opt-in live PostgreSQL/MinIO/cross-encoder tests pass. Any separate
  live P12 OpenSearch limitation stays recorded under its own risk.
- Required documentation, state, prompt, and test ledgers are updated before
  checkpointing.

# P12 Permission-First Hybrid Retrieval

## Scope

Implement the authenticated query retrieval path through authorized candidate
results. The phase stops before reranking, evidence resolution, context
construction, and LLM generation.

## Exit gate

- OpenFGA scope is resolved for every query before search or query embedding.
- Search filters are immutable, server-created, tenant-bound, and intersected
  with optional user constraints.
- BM25 and vector candidate paths use the same authorization filter.
- Candidate responses contain metadata and provenance only, never chunk text.
- Every fused candidate is fine-checked against current authorization before it
  is returned toward later pipeline stages.
- Retrieval fails closed on authorization failure or malformed security data.
- Tests cover tenant/account/department isolation, revocation, unavailable
  authorization, malicious narrowing filters, deterministic fusion, and zero
  unauthorized candidates crossing the downstream boundary.
- Retrieval evaluation hooks expose ranked evidence IDs and component
  diagnostics without adding model answers to runtime code.
- Required quality/security gates pass and durable state records are updated.

## Out of scope

Reranking, evidence resolution, answer generation, citation validation,
shareability enforcement for generated answers, and browser/API exposure.

PHASE ID: P15 — Confidentiality Policy & Customer-Safe Mode.

Implement deterministic confidentiality/shareability policy.

Two distinct concepts:
- can_view: whether the authenticated user may see content.
- can_share_externally: whether content may be used in a customer-safe answer.

Requirements:
- Internal Answer mode uses authorized evidence and surfaces classification warnings.
- Customer-Safe mode performs a NEW restricted evidence-selection/context-construction path requiring external_shareable policy. Do NOT send internal-only text to the model and then ask it to redact it.
- Classification/shareability decisions are deterministic policy/metadata, never LLM decisions.
- Refusal/messages should not reveal the existence/count/title of inaccessible sensitive resources unless policy explicitly permits.

Implement warning taxonomy and machine-readable policy status in responses.
Add tests:
- user can view Product internal discussion but customer-safe answer excludes it;
- customer-safe answer can still use approved customer-shareable source;
- Legal-only inaccessible content does not leak existence;
- shareability metadata missing -> conservative behavior;
- classification change affects next answer path.

Document policy precedence and exceptions. Update state/evals hooks.

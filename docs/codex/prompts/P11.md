# P11 — Embeddings & Search Index

Implement local embedding and OpenSearch indexing.

Requirements:

- embedding provider interface;
- default local implementation suitable for offline/local runtime once model artifacts are installed;
- embedding model name/version/dimension captured in configuration and index metadata;
- batch embedding with bounded memory;
- timeout/retry/error handling;
- never send source content to a cloud model in the default configuration.

OpenSearch:

- explicit versioned index mapping;
- store chunk text, vector, provenance/citation locator, tenant/account/department/classification/authority/freshness fields, parent/version IDs, and security filter references;
- BM25 text fields plus vector field;
- aliases for active index version;
- controlled reindex/migration workflow;
- index derived data is disposable/rebuildable;
- deletion/tombstone propagation removes searchable chunk/vector data.

Security:

- no search endpoint directly exposed to browser;
- index cannot be treated as authorization source;
- enforce localhost/private-network configuration;
- sanitize logs so text/vector inputs are not dumped.

Tests:

- index mapping;
- embed/index known fixture;
- deterministic metadata;
- delete;
- reindex;
- model/version mismatch fails clearly;
- restricted chunk retains required filter metadata.

Add `make reindex-demo` and relevant docs.
Do not implement user query retrieval yet.

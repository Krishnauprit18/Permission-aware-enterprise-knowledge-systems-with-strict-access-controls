# P12 Permission-First Hybrid Retrieval

## Scope

Implemented the authenticated-principal retrieval path through authorized,
metadata-only candidate results. The phase stops before reranking, evidence
resolution, context construction, citation validation, answer generation, and
external sharing.

## Delivered

- OpenFGA scope resolution precedes query embedding and search.
- Frozen server-generated authorization filters bind tenant, resources, policy
  versions, and the decision fingerprint.
- Typed account, department, and UTC update-time filters can only narrow scope.
- BM25 and vector OpenSearch candidate paths share the same filter and return
  allowlisted metadata without text or vectors.
- Deterministic RRF fusion records text-free internal rank/score diagnostics.
- Current fine authorization checks run before an authorized candidate can be
  returned toward later reranking or context construction.
- Retrieval evaluation records expose ranked IDs and security metrics without
  questions, text, vectors, or model answers.
- Local Semgrep policy and async test harness adjustments keep verification
  deterministic in the current offline/read-only host environment.

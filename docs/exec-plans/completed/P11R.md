# P11R Embeddings and Search Index Remediation Plan

## Scope

Close the P11 gaps by enabling OpenSearch k-NN, replacing runtime hash
embeddings with a real local semantic ONNX adapter, adding live OpenSearch
integration evidence, correcting the authorization/embedding invariant,
repairing archived prompt hashes, and enforcing prompt integrity in `make
verify`.

## Out of scope

P12 user query retrieval, permission-first query scope resolution, reranking,
evidence resolution, generation, and browser-facing search remain out of scope.

## Exit evidence

- `index.knn=true` is part of every created generation.
- FastEmbed BGE-small is a pinned optional local runtime; reindex requires a
  local model cache and `local_files_only=True`. The hash provider is test-only.
- Live tests create generations, bulk index fixture chunks, inspect mappings,
  run ANN and BM25 queries, cut over aliases, delete data, and clean up.
- P01/P02 prompt hashes match their archived files and automated integrity
  checking is part of `make verify`.
- Durable state and ledgers record the remediation evidence and this plan moves
  to `completed/`.

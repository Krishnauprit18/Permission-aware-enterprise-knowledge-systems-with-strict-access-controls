# P08: Synthetic Enterprise Dataset

- Status: `completed`
- Owner: implementation engineer
- Created: 2026-09-13
- Exit gate: deterministic dataset validation and all applicable repository checks pass.

## Objective

Create a realistic, entirely synthetic Northstar enterprise corpus that can
drive the local demo and later permission-aware retrieval and evaluation work.

## In scope

- Versioned manifest and source fixtures for documents, support tickets,
  Slack-style threads, call transcripts, and policies.
- Synthetic users, roles, departments, customer accounts, and Harbor Labs
  cross-tenant decoy data.
- Separate OpenFGA-compatible ACL fixture with tenant-safe resource mappings.
- At least 50 labeled golden questions with expected evidence IDs, refusal
  expectations, and explicit authority/freshness metadata.
- Deterministic validator for IDs, hashes, required scenarios, safe synthetic
  content, ACL consistency, and evidence relationships.
- Case-study timeline and dataset documentation.

## Out of scope

- Runtime ingestion, parsing, chunking, embedding, indexing, retrieval,
  authorization enforcement, answer generation, or model integration.
- Hard-coded expected model answers in application/runtime code.

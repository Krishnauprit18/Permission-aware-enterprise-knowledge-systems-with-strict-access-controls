# P18 - Golden Dataset and Evaluation Harness

## Objective

Build a deterministic, versioned evaluation harness for the synthetic enterprise
corpus. Keep retrieval evaluation independent from generation evaluation and
make unauthorized context, cross-tenant leakage, and invalid citation
acceptance release-blocking metrics.

## Scope

- promote the 60 synthetic golden cases to a complete machine-readable contract;
- add typed retrieval and generation observations, metrics, and report writers;
- add deterministic fixture evaluation and regression diff support;
- document commands, schemas, metric interpretation, and security gates;
- add focused tests and wire the fast evaluation into repository verification.

## Non-goals

- no new retrieval, reranking, evidence, or generation behavior;
- no answer generation or LLM judge in the default evaluator;
- no hosted evaluation service or cloud dependency;
- no runtime authorization changes.

## Exit gate

1. `make eval` validates the corpus, evaluates retrieval and generation as
   separate inputs, and writes versioned JSON plus Markdown/HTML reports.
2. Recall@K, precision@K, MRR, nDCG, citation, refusal, conflict, temporal,
   warning, and grounding metrics are covered by deterministic tests.
3. Unauthorized Context Rate, Cross-Tenant Leakage, and Invalid Citation
   Acceptance are zero; any nonzero value returns a nonzero evaluation exit
   status.
4. A deterministic regression diff is produced against the prior report when
   one is available.
5. `make verify` and applicable release checks pass, and all state ledgers and
   the sanitized prompt archive are updated.

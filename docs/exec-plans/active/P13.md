# P13 Reranking And Evidence Resolution

## Scope

Consume only `P12` authorized candidates. Implement bounded local pairwise
reranking, an authorized text-loading boundary, and deterministic evidence
resolution. This phase does not add retrieval, context construction, citation
validation, answer generation, external sharing, or an API endpoint.

## Exit gate

- The evidence service re-checks `can_view` before text is loaded or reranked.
- Reranking is local, bounded, deterministic, and cannot add a candidate.
- Fallback keeps the already-authorized P12 order on reranker timeout/failure.
- Evidence packets preserve provenance, source/version/freshness/authority,
  classification/shareability, supersession, conflicts, and trace diagnostics.
- Required conflict, supersession, duplicate, authorization, and fallback tests
  pass with the standard fast quality/security gate.

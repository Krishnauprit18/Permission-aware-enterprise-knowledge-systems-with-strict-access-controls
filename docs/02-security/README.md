# Security

Threats, authorization policy, trust boundaries, secure configuration, security findings, and verification evidence live here. Security decisions are code- and policy-driven, never delegated to an LLM.

- `STANDARDS_ALIGNMENT.md` defines standards used as verification guidance only.
- `THREAT_MODEL.md` records the P01 STRIDE and LLM/RAG threat register with planned mitigations and tests.
- `VERIFICATION_MATRIX.md` maps planned evidence to the requested security references without claiming certification.
- `SECURITY_FINDING_TEMPLATE.md` is the required format for security findings.

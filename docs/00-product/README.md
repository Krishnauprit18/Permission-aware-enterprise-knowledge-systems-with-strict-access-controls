# Product

Product intent, scope boundaries, user-facing invariants, and acceptance language live here. Implementation details belong in architecture or engineering documents.

- `PRODUCT_INVARIANTS.md` records the security-sensitive product properties established at bootstrap.
- `SYSTEM_INVARIANTS.md` is the normative P01 invariant registry.
- `PRODUCT_SPECIFICATION.md` is the normative P01 product contract.
- `USER_JOURNEYS.md` defines the ten required synthetic user journeys and their future test assertions.

# P10 Phase Prompt

PHASE ID: P10 — Parsing, Normalization, Classification & Chunking.

Implement parsing/normalization/chunking.

Source-aware behavior:
- documents: heading/section-aware;
- Slack: parent message + thread-aware;
- tickets: ticket metadata + coherent comment windows;
- transcripts: speaker-turn/window-aware;
- policies/contracts if present: section/clause-aware.

Hard requirements:
- do not use naive fixed-character splitting as the only strategy;
- enforce max document/chunk/token/line sizes;
- preserve deterministic chunk IDs;
- every chunk carries parent document ID/version, source/account/department/timestamp/classification/external-shareable/authority metadata and authorization references needed downstream;
- ACL/classification metadata propagation is mandatory and test-asserted;
- preserve page/section/message/ticket locators for citations;
- normalize Unicode safely;
- strip/handle active content as data, never execute embedded HTML/scripts/macros;
- retrieved instructions contained in content remain ordinary text.

Classification:
- deterministic metadata rules first;
- do not ask an LLM to decide access level;
- unknown classification defaults to a conservative level according to documented policy.

Add tests for:
- tiny/huge docs;
- empty content;
- malformed Unicode;
- nested threads;
- tables/code blocks;
- prompt-injection text;
- restricted parent ACL propagation;
- versioned docs;
- locator reconstruction.

Add chunking metrics and fixtures but no embedding/index yet.
Update docs/state and archive P10 prompt.

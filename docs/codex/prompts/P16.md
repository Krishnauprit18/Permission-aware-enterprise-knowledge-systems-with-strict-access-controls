PHASE ID: P16 — Product API & Web UI.

Build the user-facing application on top of existing backend services.

UI must show:
- question input/history appropriate for local demo;
- answer;
- source citations with title/source/date and permitted excerpt;
- conflict/staleness indicators;
- internal confidentiality warning;
- Internal vs Customer-Safe mode;
- "Why this answer?" evidence/provenance view WITHOUT chain-of-thought;
- clear no-evidence/refusal states;
- trace/request ID for debugging.

Security:
- no direct OpenSearch/Postgres/OpenFGA/MinIO credentials in browser;
- safe text rendering; sanitize any allowed rich text;
- CSP and security headers;
- avoid dangerouslySetInnerHTML unless a reviewed sanitizer is unavoidable;
- CSRF/session controls consistent with auth ADR;
- no bearer token localStorage;
- no secrets or raw stack traces in UI;
- enforce backend authorization regardless of UI state.

API:
- versioned endpoints;
- request/response validation;
- bounded query size;
- structured error envelope;
- idempotency only where relevant;
- OpenAPI generated/validated.

Tests:
- component/unit tests;
- API contract tests;
- Playwright E2E for login -> query -> citations;
- users with different permissions;
- customer-safe mode;
- XSS payload in source content rendered harmlessly.

Keep visual design professional and simple; prioritize correctness/evidence.

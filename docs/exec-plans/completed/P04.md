# P04: Local Platform via Docker Compose

- Status: `completed`
- Owner: implementation engineer
- Created: 2026-09-13
- Exit gate: `PASS` for the local platform and full available verification. The destructive live reset was dry-run verified but not executed; MinIO root posture remains an explicit future hardening risk.

## Objective

Provide a local-only, private Docker Compose platform for the accepted P02 infrastructure stack without product business behavior.

## Delivered

- PostgreSQL, OpenSearch, Keycloak, OpenFGA, MinIO, OpenTelemetry Collector, Jaeger, and Prometheus on a private internal network.
- Pinned service references, architecture-correct MinIO digests, loopback host bindings, named volumes, resource limits, healthchecks, dependency conditions, and deterministic bootstrap.
- Generated mode-600 local credentials, portable smoke checks, `make up`, `make down`, `make reset-demo`, and `make platform-status` operations.
- Operations runbook, Docker context exclusions, pinned local ShellCheck/Trivy fallbacks, and state evidence.

## Out of scope

- Product schemas, connectors, ingestion, retrieval, model adapters, application APIs, authorization tuples, demo content, Kubernetes, cloud services, external telemetry, and Redis.

## Evidence

- `make platform-config`: PASS.
- `make up`: PASS with health-gated dependencies, successful OpenFGA migration, and successful MinIO initializer.
- `make platform-status`: PASS for all service readiness/version/schema probes, using private-network fallback for the active VM-backed Docker context.
- `make container-lint`: PASS with Compose validation and Docker BuildKit checks.
- `make shellcheck`: PASS using pinned local container fallback.
- `make container-scan`: PASS using pinned Trivy `0.56.2` container fallback with embedded checks.
- `make verify`, `make scan`, `make sbom`, and `make verify-release`: PASS.
- `make -n reset-demo`: PASS; the live destructive reset was not run without explicit deletion approval.

## Risks and recovery

- MinIO runs as root in the current pinned image configuration and is documented for future hardening.
- Keycloak development mode and unauthenticated plaintext OpenFGA are restricted to the loopback-bound local platform and are not production settings.
- `make down` preserves named volumes. `make reset-demo` removes this project’s named volumes and recreates an empty platform; it does not remove `.env.local` or images.

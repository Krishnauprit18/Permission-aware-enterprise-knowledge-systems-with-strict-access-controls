# Standards Alignment Guidance

The project may use recognized standards as engineering verification guidance. This document does not assert certification, accreditation, compliance, or conformance.

## Intended references

- NIST Secure Software Development Framework (SSDF) for secure development practices and evidence.
- OWASP Application Security Verification Standard (ASVS) for application security requirements.
- OWASP Top 10 for Large Language Model Applications for LLM-specific threat coverage, where applicable.
- NIST AI Risk Management Framework (AI RMF) for risk identification and evaluation vocabulary, where applicable.

## Evidence rule

Each claim of alignment must point to a specific requirement, implementation or test, and dated evidence in the repository. Use wording such as "aligned to" or "verified against" only when evidence supports it. Never describe the product as certified or compliant based solely on this document.

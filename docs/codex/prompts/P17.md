# PHASE ID: P17 - Auditability & Observability

Implement structured observability and security auditability.

Per query capture safely:
- request/trace ID;
- pseudonymous/stable user subject ID;
- tenant ID;
- authorization scope/fingerprint/version (not secret graph dump);
- normalized query metadata;
- BM25/vector candidate IDs and ranks;
- fusion/rerank diagnostics;
- evidence IDs actually sent to model;
- document versions;
- prompt template version;
- model adapter/model identifier;
- citation validation result;
- latency breakdown;
- token/context size metrics where available;
- policy warnings;
- final outcome/error class.

Never log:
- access tokens/session cookies;
- secret values;
- full confidential documents by default;
- embedding vectors;
- hidden chain-of-thought.

Define redaction tests.

Instrument connector/ingestion/query pipeline with OpenTelemetry spans.
Provide a local trace viewer and minimal metrics dashboard/queries useful for debugging.
Create audit events for login-relevant security events, authz denials, role changes, ingestion/deletion, policy changes, and admin actions if present.

Tests:
- sensitive token redaction;
- trace correlation end to end;
- failed authz records a safe event;
- user-facing logs do not leak restricted content;
- observability outage does not bypass security or crash core request unexpectedly.

Update operations docs and state.
